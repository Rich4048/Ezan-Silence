# Ezan Silence

Welcome to the official GitHub repository for **Ezan Silence**! 

## ⚠️ Beta Notice
* **Release Date:** Tomorrow
* **Auto-Mute Feature:** Does not work on the beta version; it will only work after the official release.
* **Accuracy:** Prayer times may be inaccurate during this beta phase.
* More updates are incoming!

## Features
* Clean and simple classic interface.
* Fetches live prayer times using the AlAdhan API.
* Support for Standard/Diyanet and Moon Calculation (Moonsighting) methods.
* Automatic country and city detection from your input.
